# APEIRON Global Mute Overlay

Программа для Windows: горячие клавиши микрофона и настраиваемый экранный индикатор. Бесплатная, с открытым исходным кодом под MIT.

Версия **0.1.0-beta.2**, Windows 10/11 x64. [English](README.md).

## Язык скачивания

Выберите архив с **RU** или **EN** в названии. Язык интерфейса задан в сборке, переключателя в программе нет. Обе сборки используют одинаковые настройки и не запускаются одновременно.

- `APEIRON-Global-Mute-Overlay-v0.1.0-beta.2-RU-win-x64.zip`
- `APEIRON-Global-Mute-Overlay-v0.1.0-beta.2-EN-win-x64.zip`

В этой ветке подготовлена beta.2. Её архивы ещё не опубликованы как релиз GitHub.
[Опубликованные релизы](https://github.com/iamtheapeiron-web/apeiron-global-mute-overlay/releases).

## Возможности

- Переключение состояния одного выбранного микрофона Windows.
- Временное изменение состояния при удержании клавиши с восстановлением при отпускании.
- Настройка положения, формы, размера, прозрачности, цветов и правил показа индикатора.
- Отдельная блокировка клавиш переключения и удержания, общий переключатель в окне, трее и по назначаемому сочетанию.
- Пауза горячих клавиш с сохранением контроля состояния и ручного управления.
- Необязательное восстановление из файла, предложение запуска от администратора и автозапуск Windows.

## Новое сочетание

«Управление» - «Сочетание для блокировки клавиш» - «Назначить сочетание».
Нажмите Ctrl, Alt или Shift с другой клавишей, отпустите все клавиши и сохраните настройки. По умолчанию сочетание не назначено.

Команда меняет только общую блокировку. Даже при выключенной блокировке управление микрофоном продолжает работать. Само сочетание зарезервировано для команды в других приложениях; модификаторы передаются как обычно. Пауза горячих клавиш останавливает и сочетание. Автоповтор не создаёт повторных переключений.

Основная клавиша может совпадать с клавишей переключения или удержания: полное сочетание не меняет микрофон. Модификаторы сочетания нельзя использовать как активные отдельные клавиши микрофона. Сочетания с Windows, Esc и Ctrl+Alt+Delete не назначаются.

## Обновление

Сохраните настройки и выйдите из старой версии через трей. Распакуйте выбранный архив в постоянную папку и запустите EXE. Устройства, клавиши и оформление сохранятся. При переносе EXE сохраните настройки заново для обновления пути автозапуска.

[Подробная инструкция](docs/README_RU.txt), [короткая проверка в Windows](docs/WINDOWS_CHECKLIST_RU.txt), [сборка из исходников](BUILDING.md).

Это бета без цифровой подписи. Монопольный доступ к аудио может обходить программное отключение, эксклюзивный полноэкранный режим - скрывать индикатор. Работа в играх зависит от прав и ограничений ввода. Автоматические проверки используют тестовый аудиобэкенд. Реальные устройства, перехват ввода, UAC, игры и размещение текста beta.2 нужно проверить в Windows. [Отчёт](TEST_REPORT.txt).

При ошибке укажите действие, ожидаемый и фактический результат, версию Windows, микрофон и игру. По возможности приложите «Общие» - «Скопировать диагностику».
