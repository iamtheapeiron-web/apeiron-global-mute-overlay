# APEIRON Global Mute Overlay

Управление системным mute выбранного микрофона с помощью глобальных клавиш и настраиваемого оверлея. OBS не требуется.

**Версия:** `v0.1.0-beta.1`  
**Платформа:** Windows 10/11 x64  
**Статус:** Beta, EXE без цифровой подписи

## Скачать и запустить

Скачайте Windows ZIP в [Releases](https://github.com/iamtheapeiron-web/apeiron-global-mute-overlay/releases), распакуйте в постоянную папку и запустите `APEIRON_Global_Mute_Overlay.exe`.

1. В **Microphone** выберите микрофон и нажмите **Use selected microphone**.
2. В **Controls** назначьте клавиши. По умолчанию **F9 - Toggle, F10 - Hold**.
3. Настройте внешний вид и нажмите **Save settings**.

Перед обновлением закройте предыдущую версию через трей - **Exit**. Настройки устройства, клавиш и оформления сохраняются.

## Управление

- **Toggle** переключает системный mute.
- **Hold** временно использует противоположное состояние; отпускание восстанавливает исходное.
- **Pause hotkeys** приостанавливает оба действия. Мониторинг и ручное управление продолжают работать.
- **Block keys in other apps** управляет передачей назначенных клавиш. Если выключить, Toggle/Hold продолжают работать вместе с обычным действием клавиш.
- Раздельные настройки блокировки Toggle/Hold находятся в **Controls**.

Пауза и общая отмена блокировки действуют до выхода. После нового запуска пауза снята, общая блокировка включена с вашими сохранёнными отдельными настройками.

## Возможности

- Настройка положения, формы, размера, прозрачности и цветов оверлея.
- Отдельные правила показа для обычных изменений и Hold.
- Привязка к одному устройству независимо от микрофона по умолчанию Windows.
- Трей, необязательный автозапуск и предложение перезапуска от администратора.
- Исходное состояние Hold в памяти; восстановление в файл включается отдельно.
- Копирование диагностики для обратной связи.

## Ограничения беты

Программа не записывает звук и не меняет усиление. Mic ON означает отсутствие системного mute, а не наличие аудиосигнала. Отдельный mute приложений и физический выключатель без уведомления Windows не видны.
Программный mute может обходиться эксклюзивным доступом к аудио.
Полноэкранная игра может скрывать оверлей. Права процессов и ограничения игры могут влиять на доставку клавиш.

Основные функции проверены на системе владельца. Совместимость с другими микрофонами и играми уточняется по обратной связи. Автотесты моделей логики не заменяют проверки настоящего оборудования.
