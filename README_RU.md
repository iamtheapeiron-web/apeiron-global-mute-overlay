# APEIRON Global Mute Overlay

**0.1.0-beta.4 RU** - русская бета для Windows 10/11 x64. MIT.

## Что изменено

- Один переключатель блокирует клавиши всех включённых функций микрофона. Отдельные галочки переключения и удержания удалены.
- Выключенная функция микрофона не резервирует свою клавишу. Общая блокировка изначально выключена; сохранённое состояние восстанавливается.
- Команда блокировки: одна обычная клавиша, Ctrl/Alt/Shift + клавиша либо левый и правый Shift, Alt или Ctrl одновременно.
- Пара срабатывает при нажатии второй стороны, без повторов до отпускания обеих. Первая сторона сохраняет обычное действие в приложении.
- Одиночная команда должна отличаться от обеих клавиш микрофона. Конфликты модификаторов с активными функциями отклоняются.
- Переключение блокировки сохраняет состояние микрофона и активное удержание.

Для сохранения команды и общей блокировки используйте «Сохранить настройки». Пауза снимается после перезапуска. Ранее сохранённое сочетание, микрофон, оформление и положение сохраняются; старые отдельные настройки блокировки игнорируются.

Все изменения beta.3 сохранены: компактные настройки, прозрачность 0-95%, цветные образцы, списки правил показа, отметка несохранённых изменений и удержание в памяти без нового файла восстановления.
