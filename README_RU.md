# APEIRON Global Mute Overlay

**0.1.0-beta.3 RU** - русская сборка с упрощённым интерфейсом. Windows 10/11 x64, MIT. Английская сборка этого обновления пока не подготовлена.

## Что изменено

- Блокировка изначально выключена, если сохранённого выбора нет. Общий переключатель теперь сохраняется через «Сохранить настройки»; индивидуальные настройки остаются.
- Блокировка и её сочетание объединены. Строка под галочкой показывает фактический результат. Сочетание можно отключить без удаления назначения либо очистить.
- Правила показа перенесены в «Оформление» и представлены двумя списками без удаления режимов.
- Прозрачность 0-95% с ползунком и числом. Старые значения пересчитываются без изменения внешнего вида.
- Цветные образцы, заметная рамка белого цвета и понятный предпросмотр без изменения микрофона.
- Удалены поля X/Y. Перетаскивание, выбор угла/монитора и сохранение положения работают как раньше.
- Постоянная отметка несохранённых изменений. Пауза, предпросмотр и изменение состояния микрофона не считаются изменением настроек.
- Удалена опция записи восстановления в файл. Новые удержания используют память. Старый файл обрабатывается при обновлении.
- В RU удалено пояснение про раскладку США. В английском исходнике оно сохранено.

Содержимое вкладки «Микрофон» и основное поведение переключения/удержания сохранены. Дополнительных значков трея нет. Пауза снимается после перезапуска, а общая блокировка восстанавливается из сохранённых настроек.

## Проверка

Это бета для проверки в Windows. Автоматические проверки используют тестовый аудиобэкенд. Интерфейс осмотрен в отдельном окне Mono/Linux с тем же C# кодом и совместимым тестовым значком. Это не проверка реального Windows-аудио, перехвата ввода, UAC, автозапуска или игр.

[Инструкция](docs/README_RU.txt), [короткая проверка Windows](docs/WINDOWS_CHECKLIST_RU.txt), [отчёт](TEST_REPORT.txt), [сборка из исходников](BUILDING.md).
