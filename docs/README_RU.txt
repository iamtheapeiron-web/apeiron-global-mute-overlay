APEIRON Global Mute Overlay
v0.1.0-beta.1 | Windows 10 / 11, 64-bit

Первая бета. Основные функции проверены автором на своей системе.
Совместимость с другими устройствами и играми уточняется по обратной связи.
Добровольные дополнительные проверки: WINDOWS_CHECKLIST_RU.txt.

ОБНОВЛЕНИЕ
Сохраните настройки в старой версии и закройте её через трей - Exit.
Распакуйте новый архив в постоянную папку и запустите EXE.
Микрофон, клавиши, оформление и отдельные настройки блокировки сохраняются.
Если EXE перенесён, примените Save settings для обновления пути автозапуска.

ПЕРВЫЙ ЗАПУСК
1. Запустите APEIRON_Global_Mute_Overlay.exe.
2. Microphone: выберите микрофон и нажмите Use selected microphone.
3. Controls: назначьте клавиши. По умолчанию F9 - Toggle, F10 - Hold.
4. Appearance: настройте отображение и при необходимости положение.
5. Нажмите Save settings. X скрывает окно в трей; Exit завершает приложение.
Используется .NET Framework 4.x в Windows. OBS, Python, PowerShell
и отдельные модули не нужны. Приложение не записывает звук.

УПРАВЛЕНИЕ И БЛОКИРОВКА
Toggle переключает системный mute выбранного микрофона.
Hold временно использует противоположное состояние и восстанавливает
исходное после отпускания. Toggle во время Hold игнорируется.
Изменение mute другой программой во время Hold исправляется на временное
состояние; отпускание возвращает исходное состояние.

В меню трея:
- Pause hotkeys: приостановить оба действия и пропускать новые нажатия.
  Активный Hold восстанавливается. Мониторинг, оверлей, ручные кнопки
  Mute / Unmute и Test продолжают работать.
- Block keys in other apps: общий переключатель блокировки передачи клавиш.
  Выключен - обе клавиши проходят в другие приложения, Toggle/Hold работают.
  Включён - применяются отдельные Block Toggle / Hold key в Controls.

Оба общих переключателя также доступны в Controls.
Общий переключатель блокировки не меняет отдельные галочки и mute микрофона.
Отдельные галочки можно изменить и во время паузы или общей отмены блокировки.
После нового запуска пауза выключена, общая блокировка включена,
применяются сохранённые отдельные настройки. Эти два временных режима
не сохраняются даже при Save settings; отдельные настройки сохраняются.

Текущее нажатие сохраняет прежнее правило передачи до отпускания.
После снятия паузы уже зажатая клавиша ждёт полного отпускания.
Основные кнопки мыши (левая, правая, средняя) никогда не блокируются.
Собственное окно настроек и назначение клавиши пропускают нажатия.
Пунктуационные клавиши подписаны по US-разметке; например, ` / ~ (US).
Это подпись: назначенная клавиша после обновления не меняется.
Поддерживаются отдельные клавиши клавиатуры и кнопки мыши; сочетания,
колесо мыши и прямой ввод с геймпада не предусмотрены.

ОТОБРАЖЕНИЕ
MUTED означает, что системный mute выбранного устройства включён.
Mic ON означает, что системный mute выключен; это не измеритель аудиосигнала.
Отдельный mute в Discord/OBS и физический выключатель, не сообщающий
состояние Windows, приложению не видны.
Выберите физический микрофон для управления перед виртуальной обработкой.
Normal microphone changes задаёт обычные правила показа.
Keep visible while muted держит оверлей видимым при MUTED.
During Hold Mode отдельно задаёт показ во время удержания.
Always show while held держит оверлей видимым до отпускания.
Popup duration задаёт краткие показы и Test-превью; постоянные показы
от таймера не зависят. Отпускание Hold не создаёт отдельного popup.
Test не меняет микрофон и временно заменяет его отображение.
При размещении перетащите оверлей и нажмите зелёную Finish placement.
X или Hide to tray также завершают размещение.

УСТРОЙСТВО И ВОССТАНОВЛЕНИЕ
Выбор привязан к точному устройству, независимо от микрофона по умолчанию.
После отключения приложение ждёт возвращения того же устройства.
При неизвестном состоянии реальное отображение скрывается.
Test-превью остаётся доступным и не является показанием устройства.
По умолчанию Hold хранит исходное состояние в памяти.
Отпускание, пауза, выключение Hold и обычный Exit восстанавливают доступное
устройство. Если оно недоступно, восстановление ждёт в памяти.
Завершение приложения до восстановления теряет эту информацию.
General - Save Hold recovery to a file сохраняет восстановление между
запусками. Файл создаётся до изменения mute и удаляется после восстановления.
Файл от старой версии обрабатывается и при выключенной опции.
Переключение опции во время Hold не меняет mute. Буферизация Windows
не гарантирует сохранение при внезапном отключении питания.

ПРАВА И АВТОЗАПУСК
General показывает права и содержит Restart as Administrator.
Ask about Administrator rights at startup включает вопрос при запуске
без подтверждённых прав администратора. Вопрос задаётся один раз за сеанс.
При повышенном запуске вопрос не нужен; в заголовке видно [Administrator].
Его можно отключить и сохранить выбор через Save settings.
При различии прав с активной программой доступно предупреждение.
Отмена Windows UAC оставляет текущий экземпляр работающим.
При незавершённом восстановлении только в памяти перезапуск блокируется:
верните микрофон или включите сохранение восстановления в файл.
Start with Windows применяется через Save settings и запускает EXE в трее
с обычными правами. Включённый вопрос об администраторе может открыть окно.
Второй экземпляр программы не запускается.

ДИАГНОСТИКА И ОГРАНИЧЕНИЯ
General - Copy diagnostics копирует состояние и измерения обработки.
Open settings folder открывает папку:
%LOCALAPPDATA%\APEIRON_Global_Mute_Overlay
Настройки OBS Overlay хранятся отдельно.
Программа управляет одним устройством записи. Программный mute может
обходиться эксклюзивным доступом к аудио. Оверлей может быть скрыт
exclusive fullscreen; используйте оконный или безрамочный режим.
Доставка клавиш зависит от прав и ограничений игры. EXE не подписан.

В архиве есть исходники, результаты автоматических проверок и контрольные
суммы. Здесь проверены модели логики и Windows EXE; реальные Windows
Core Audio, перехват клавиш, UAC и интерфейс в среде сборки не запускались.
