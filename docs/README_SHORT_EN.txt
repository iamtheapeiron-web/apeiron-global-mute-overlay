APEIRON Global Mute Overlay
v0.1.0-beta.5 | EN | Windows 10/11 x64

STARTING AND UPDATING
1. Exit the previous version from its tray menu.
2. Extract this archive to a permanent folder and run
   APEIRON_Global_Mute_Overlay.exe.
3. On Microphone, choose a device and click Use selected microphone.
4. Assign keys on Controls, configure the indicator on Appearance,
   then click Save settings.

Existing settings are preserved when updating.
The RU or EN archive determines the language; both builds share settings.
Only one instance can run at a time.

CONTROLS
Defaults: F9 toggles mute; F10 temporarily reverses the microphone state.
Releasing F10 restores its original state.

Master blocking lets microphone hotkeys control the mic without triggering
other apps. With blocking off, the same keys still control the microphone.
Disabling an action also stops reserving its key.

To toggle blocking, assign one key, a Ctrl/Alt/Shift + key combination,
or both Left and Right Shift, Alt or Ctrl. A pair fires on the second modifier.
Release both sides before repeating.

Pause operation stops responding to assigned keys. Clear the checkbox to resume.
Pause clears at restart. Use Save settings to keep your changes.
Closing the window hides it in the tray; Exit closes the program.

The app does not record audio. Requires .NET Framework 4.x.
