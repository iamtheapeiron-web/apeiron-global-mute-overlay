APEIRON Global Mute Overlay
v0.1.0-beta.5 | RU | Windows 10/11 x64

ЗАПУСК И ОБНОВЛЕНИЕ
1. Завершите предыдущую версию через «Выход» в трее.
2. Распакуйте архив в постоянную папку и запустите
   APEIRON_Global_Mute_Overlay.exe.
3. На вкладке «Микрофон» выберите устройство и нажмите
   «Использовать этот микрофон».
4. Назначьте клавиши на вкладке «Управление», настройте индикатор
   на вкладке «Оформление» и нажмите «Сохранить настройки».

При обновлении прежние настройки сохраняются.
Язык определяется архивом RU или EN; обе версии используют общие настройки.
Одновременно работает один экземпляр программы.

УПРАВЛЕНИЕ
По умолчанию F9 переключает микрофон, F10 временно меняет состояние
на противоположное. Отпускание F10 возвращает исходное состояние.

Общая блокировка позволяет клавишам управлять микрофоном, не вызывая
действий в других приложениях. Без блокировки микрофон продолжает
реагировать на те же клавиши. Для отключённой функции клавиша не блокируется.

Для переключения блокировки можно назначить отдельную клавишу,
сочетание Ctrl/Alt/Shift с клавишей или пару левого и правого Shift, Alt или Ctrl.
Пара срабатывает при нажатии второго модификатора. Для повтора отпустите оба.

«Приостановить работу» отключает реакцию на назначенные клавиши.
Снимите галочку, чтобы возобновить работу. После перезапуска пауза снята.
Изменения сохраняются кнопкой «Сохранить настройки».
Крестик скрывает окно в трей; «Выход» завершает программу.

ДОПОЛНИТЕЛЬНО
Для игры с правами администратора запустите утилиту с теми же правами.
Программа не записывает звук. Требуется .NET Framework 4.x.
Это бета-версия без цифровой подписи. Подробности и ограничения:
https://github.com/iamtheapeiron-web/apeiron-global-mute-overlay/blob/main/docs/README_RU.txt
