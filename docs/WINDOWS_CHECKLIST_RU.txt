APEIRON Global Mute Overlay v0.1.0-beta.1
Добровольные дополнительные проверки на Windows

Проходить весь список для использования беты не требуется.
При проблеме достаточно описать действие, ожидаемый и фактический результат
и приложить General - Copy diagnostics. Ниже - дополнительные сценарии.
Среда сборки не выполнила их на настоящей Windows.
Используйте свои сохранённые клавиши. F9/F10 - значения по умолчанию.
Проверьте Hold из обоих исходных состояний: Mic ON и MUTED.

1. Обновление.
   Save settings в старой версии, Exit, запуск беты. Сохранены микрофон,
   клавиши, цвета и положение. В заголовке и About - 0.1.0-beta.1.

2. Общая блокировка.
   В трее один Block keys in other apps и отдельный Pause hotkeys.
   При Block Hold включено / Block Toggle выключено общая блокировка
   применяет именно эти галочки. Выключите общий пункт: обе клавиши
   проходят в текстовый редактор, но продолжают управлять mute.
   Включите: отдельный выбор вернулся. Повторите с обеими галочками
   и с обеими выключенными. Основные клики мыши всегда доступны.

3. Переключение при удержании.
   Зажмите Hold и мышью переключите общую блокировку в обе стороны.
   Mute остаётся временным и восстанавливается после отпускания.
   Новая передача применяется со следующего нажатия.
   Проверьте короткие тапы и удержание 3-5 секунд.

4. Пауза.
   Включите Pause hotkeys при Hold: исходный mute восстанавливается.
   Клавиши проходят в другие окна и не меняют mute.
   Ручной Mute / Unmute, внешний mute Windows и оверлей работают.
   Снимите паузу при зажатой клавише: она начинает работать после
   отпускания и нового нажатия. Отдельные галочки не меняются.

5. Сохранение.
   При паузе и выключенной общей блокировке нажмите Save settings и Exit.
   Новый запуск: пауза снята, общая блокировка включена, отдельные
   настройки и назначенные клавиши сохранены.

6. Сон и блокировка сеанса.
   Проверьте сон/пробуждение и блокировку/разблокировку Windows,
   включая переход при активном Hold. Доступный микрофон восстанавливается;
   после возвращения проверьте свежие нажатия и отсутствие зависшего Hold.

7. Отключение микрофона.
   Отключите выбранный USB-микрофон при Hold, отпустите клавишу,
   подключите обратно: восстанавливается его исходное состояние.
   Другое устройство не выбирается автоматически. Смена устройства
   по умолчанию Windows не меняет выбранный микрофон приложения.

8. Восстановление в файл.
   Без опции обычный Hold не создаёт hold-recovery.xml.
   С опцией файл появляется при Hold и удаляется после восстановления.
   С включённой опцией отключите микрофон при Hold, закройте приложение,
   запустите снова и верните микрофон: восстановление завершается.

9. Администратор и игра.
   Проверьте вопрос при обычном запуске без игры; No не повторяет его
   в том же сеансе. Отмена Windows UAC оставляет текущий экземпляр.
   Подтверждение запускает один новый экземпляр с сохранёнными настройками.
   Проверьте клавиши в используемой игре при одинаковых правах процессов.

10. Автозапуск.
    Start with Windows + Save settings, повторный вход в Windows:
    запускается приложение с выбранным устройством. Включённый вопрос
    об администраторе может открыть окно. Второй запуск не создаёт копию.

11. Отображение.
    Проверьте краткие popup, Keep visible while muted, Always show while held,
    Test-превью и зелёную Finish placement. Отпускание Hold не даёт лишний
    popup; X завершает размещение. Проверьте используемый масштаб Windows.

12. Другой компьютер.
    Новый профиль и другой микрофон: выбор с нуля, Toggle/Hold, сохранение
    и повторный запуск. Личный файл настроек переносить не нужно.

При сбое скопируйте General - Copy diagnostics и запишите номер проверки,
исходное состояние, действие и фактический результат.
